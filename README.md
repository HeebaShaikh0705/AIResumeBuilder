# AI Resume Builder

An AI-powered Resume Builder developed with Python, Tkinter, Gemini AI, and ReportLab. The application collects user information such as education, skills, projects, and target role, then generates an ATS-friendly professional resume using Gemini AI. Users can preview the generated resume and save it as a formatted PDF file.

### Features
- User-friendly Tkinter GUI
- AI-generated ATS-friendly resumes
- Customizable target role
- PDF export functionality
- Automatic section formatting and headings
  
### Technologies Used
- Python
- Tkinter
- Google Gemini AI
- ReportLab
